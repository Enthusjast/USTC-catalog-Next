# 本机数据与离线应用

## 存储范围

| 存储                                                | 内容                                          | 清除查询缓存 | 清除全部本机数据 |
| --------------------------------------------------- | --------------------------------------------- | ------------ | ---------------- |
| IndexedDB `ustc-catalog-cache/queries`              | 校验后的公开查询及已读归档，最多 100 条       | 清除         | 清除             |
| IndexedDB `ustc-catalog-workspace/workspaces`       | 版本 2 工作区、修订号、方案、收藏及扩展元数据 | 保留         | 清除             |
| localStorage `catalog:workspace`                    | 版本 1 旧工作区，成功迁移前保留               | 保留         | 清除             |
| localStorage `catalog:planner`、`catalog:favorites` | 旧格式，成功迁移前保留                        | 保留         | 清除             |
| localStorage `catalog:filters`、`catalog:theme`     | 筛选与主题偏好                                | 保留         | 清除             |
| sessionStorage `catalog:classroom-positions`        | 最近 10 组教室查询的纵向及逐层横向位置        | 保留         | 清除             |
| `catalog:demo:*`                                    | 隔离开发样本的旧/新存储                       | 保留         | 清除             |
| Cache Storage                                       | 离线应用代码、样式、图标与入口                | 保留         | 保留             |

全部清除同时重置当前页面的方案、收藏与筛选状态，并恢复浅色主题；应用安装与离线程序文件保留。移除应用代码可通过浏览器的站点数据设置完成。存储移除失败会显示“清除未完成”，不会宣称成功。不清除同一来源下其他工具的无关键。

## 迁移与方案

- 每个学期最多 20 个方案，每个方案最多 100 个教学班；收藏最多 1000 门。
- 版本 1 工作区及旧学期清单迁入独立 IndexedDB；更早清单迁为“默认方案”。事务成功后才删除未被其他页面改变的旧键，失败保留原数据。
- 每次规划写入通过读写事务读取最新工作区并增加修订号。跨标签页通知和窗口恢复时重读同步数据；加入与移除使用明确目标状态，过期名称草稿和已删除方案不能覆盖新状态。
- 活动方案决定候选状态、时间冲突和考试关联。删除最后一个方案后创建空默认方案。
- 首周周一和课节表随方案保存，属于规划设置；ICS 仍须明确填写日期及选择钟点映射。
- 本机方案不进入分享链接；URL 只保存公开查询与视图参数。

## JSON 备份

备份格式标识为 `USTC-catalog-Next-backup`，新版导出 `version: 2`，支持导入版本 1 和 2。包含所有学期方案、收藏、日历设置和导出时间，不含查询缓存、筛选、主题及浏览位置。文件上限 5 MB。

导入先校验格式、版本、字段和上限，再预览数量。确认后为导入方案生成新标识，同名追加序号；收藏按编号合并去重，已有活动方案保持不变。整个工作区通过一次 IndexedDB 事务保存。格式异常、合并超限或存储失败时不替换原工作区。

## 离线和版本更新

生产环境采用 `vite-plugin-pwa` 的提示更新机制。首次联网安装 Service Worker 后，所有页面路由代码和样式均已预缓存；通过断网刷新或重新打开应用可启动。开发服务器不注册 Service Worker。

查询接口和归档 JSON 不使用 Service Worker 运行时缓存，仍由 IndexedDB 层处理。新鲜缓存可直接读取，网络失败可回退已校验旧结果；HTTP、JSON、Content-Type、schema 或公开限制异常不以旧结果覆盖。无缓存和被容量限制淘汰的查询需要联网；教室页继续隐藏查询异常文字。

出现新版本时提供小型“更新应用”按钮，选择稍后可继续使用。只有点击更新后重新载入。其他标签页激活新版时，本页仍等待点击。更新不清空查询、工作区或偏好。浏览器存储被系统清理后，需要重新联网加载及恢复 JSON 备份。
