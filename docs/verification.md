# 首版开发验证记录

验证日期：2026-10-09（Asia/Shanghai）。

## 已完成

- `npm run build`：Vue TypeScript 检查和 Vite 生产构建通过，路由拆包、CNAME 与许可证声明包含在产物中。
- 真实响应的 Zod 校验：学期、院系、课程搜索、通识/院系课程集合、计划树、计划详情、教学班、课程考试、教室公开记录、替代关系、课程详情 POST 均通过。
- 域逻辑检查：连续周、单周、例外周、未知安排、真实教学班的重叠/不重叠、重复教师安排合并。
- ICS 检查：真实教学班按周生成事件，上海时区转换为 UTC，UTF-8 75 字节折行，非连续课节分成独立事件，非法日期拒绝，通识考试单考场与含时区日期适配。
- 教室检查：存在未定位记录时，无法证明未占用的时段标为未知。
- 浏览器布局：12 个页面在 375px、768px、1024px、1440px 下未发现整体横向溢出；课程/教学班列表每页最多 25 行，周课表独立滚动。
- 移动筛选：打开后焦点进入关闭按钮，Escape 关闭，焦点返回筛选入口。
- 深浅主题与本机候选清单保存可用。

有数据的浏览器检查使用从镜像读取的真实响应写入隔离浏览器 IndexedDB，以“离线 · 缓存已过期”状态展示。检查脚本和响应样本位于临时目录，没有作为产品演示数据或测试文件提交。

## 已确认的外部限制

- `http://127.0.0.1:5173` 的实际 fetch 被镜像 CORS 拒绝；响应允许来源为 `https://catalog.enthusjast.cc`。无缓存时页面正确展示接口错误。
- 从本次浏览器环境打开 `https://catalog.enthusjast.cc` 返回连接关闭，无法据此完成正式 Origin 的跨域验收。
- JSON POST 的真实响应已从 API 域名同源读取，生产跨域 OPTIONS/POST 仍须部署后验收。
- 尚未推送或部署；GitHub Pages 设置、DNS 和 HTTPS 未通过本次开发确认。

后续上线步骤见 [部署验收清单](deployment.md)。

## 第二轮开发：关联资料与本机偏好

- 公共模块真实字段已核对：`public === id` 表示公共模块自身定义，不能当作循环引用。样本计划的课程条目由 70 条展开为 450 条，共请求 5 个唯一引用，未出现重复请求或误报循环。
- 计划详情与对比使用展开后的课程；保留本地条目和共享条目，读取失败或循环引用显式标记不完整。
- 本机筛选恢复、分享 URL 优先、同页清除不恢复旧条件均通过浏览器检查；筛选偏好包含在清除本机数据操作内。
- 课程关联按编号精确匹配。计划搜索和跨学期教学班由用户选择范围后开始，显示进度，支持取消，未读取范围不判为空结果。
