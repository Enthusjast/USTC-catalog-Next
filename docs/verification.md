## 第二轮开发：关联资料与本机偏好

- 公共模块真实字段已核对：`public === id` 表示公共模块自身定义，不能当作循环引用。样本计划的课程条目由 70 条展开为 450 条，共请求 5 个唯一引用，未出现重复请求或误报循环。
- 计划详情与对比使用展开后的课程；保留本地条目和共享条目，读取失败或循环引用显式标记不完整。
- 真实选修节点的本地学分字段为 0，而引用公共模块要求 7 学分；两级要求分别保留、展示并纳入比较，避免占位节点遗漏公共约束。
- 本机筛选恢复、分享 URL 优先、同页清除不恢复旧条件均通过浏览器检查；筛选偏好包含在清除本机数据操作内。
- 课程关联按编号精确匹配。计划搜索和跨学期教学班由用户选择范围后开始，显示进度，支持取消，未读取范围不判为空结果。
- 历史归档的 67 份静态文档、562 张课程表和 11 个版本化官方附件通过 schema 校验。表格保留表头、原列序、rowspan/colspan 与表内备注；目录与单份文档分别加载。
- 375px 历史文档表格视图无页面横向溢出；样本保留 15 个合并行单元格，显示“读取静态归档”及独立采集时间。

## 最新实现检查与真实服务观察

- 13 个页面在 375px、768px、1024px、1440px 下均未出现页面整体横向溢出。新历史正文入口采用官方 UTF-8 页面，浏览器已读取正确中文标题；课程表默认在本站读取。
- 演示模式完整交互检查通过：详情、关联计划、跨学期教学班、候选冲突、周课表、考场重叠、教室推算、完整模块比较、独立收藏列表和独立演示存储。
- HTTP、HTML、JSON、schema 和 JSONP 类型异常均保持接口错误，不用旧结果伪装成功；网络与响应流断开回退标 stale。共享请求中取消一个调用者不影响另一个，实际请求只发生一次。
- 发布构建通过；fixtures 模式构建被拒绝，发布 JS 不含 `DEMO101` 或样例课程记录。增加未知教室记录组时 schema 会拒绝，防止忽略新占用类型后误判空闲。
- 2026-10-09 23:38（北京时间），在实际 `https://catalog.enthusjast.cc` 页面发起学期 GET、课程 infos POST、教学班 infos POST，均成功读取 `200 / cors / JSON`。同日 23:28，本地 `http://127.0.0.1:5174` 也完成上述浏览器请求。
- API 同源及 Origin 头探测的 OPTIONS 返回 204，响应出现 `Access-Control-Allow-Origin: *`；带请求头的检查允许 content-type。未知路径在浏览器中仍返回 `200 + text/html`。这些配置不满足 spec 的精确来源及 JSON 404 门槛。
- GitHub Pages 最新读取：自定义域正确、`https_enforced=true`、`status=built`，但发布类型为 `legacy`。本轮开发代码没有由本次操作推送或部署，正式站点看到的版本不能代替最新代码验收。
- `npm run check:api` 当前返回非零：本机 Node HTTP 环境得到 502/HTML，与浏览器读取成功的环境有差异；同时精确 Origin 与未知路径要求未通过。脚本被加入发布任务，失败会生成 Actions 摘要并阻止该次发布。
