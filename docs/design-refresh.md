本轮实际浏览了原站的培养方案首页、课程目录、执行计划，以及开课、考试、教室和替代课程页面。

| -------------------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------ |

## 设计与交互

- 使用蓝色主色、浅色资料背景、较紧凑的标题与表格间距，深色主题同步调整。
- 页眉统一显示项目名称，搜索入口集中到导航；查询页面直接呈现标题、条件与结果。
- 首页保留全站搜索、真实当前学期及来源状态。桌面端学期卡位于搜索旁，手机端放在查询入口之后。
- 手机筛选提供背景遮罩、关闭按钮、Escape、焦点约束和“查看结果”按钮；切换到桌面宽度时恢复普通侧栏。
- 课程与教学班提供编号、名称、院系等排序；分页支持直接输入页码。
- 通修与综合素质按原站的实际集合区分。组合门类的多个来源均须成功读取；不同条目保留，完全相同的记录去重。各来源的时间与缓存状态可以展开查看，部分旧缓存不显示成完整在线读取。
- 原站的门类与接口 ID 有映射关系，页面路径的 `ma` 不能直接作为 API ID；数学类对应 `/teach/course/public/43`。

## 第二轮：查询与候选清单操作

进一步优化教学班查询及全站共用交互：

- 教学班上课安排按星期、课节、地点和周次展示，连续数字压缩为范围，非连续数字保留分隔。原始安排可展开；无法完整识别的记录始终显示提醒与原文，不据此判断无冲突。
- 候选操作同时显示图标、文字和选中状态，选中行有明确标记，并为辅助技术播报加入或移除结果。结果上方显示本机候选数量、公开时间重叠或未知状态；可直接进入管理清单，再返回查询结果。
- 列表与候选周课表使用成组的切换按钮。手机端排序与视图操作重新排布，教师、公开人数和容量增加字段标签。
- 手机筛选改用原生模态窗口，背景不可操作，焦点由浏览器管理；条件区域独立滚动，标题和“查看结果”按钮保持可见。桌面侧栏也限制最大高度，让较长的条件能滚动查看。
- 手机输入框使用 16px 字号，查询时间使用紧凑展示，同时保留完整日期的语义与提示；来源和刷新操作放在一起。320px 窄屏完整保留项目名称、搜索、主题与导航按钮。
- 导航支持 Escape、点击外部关闭及关闭后返回焦点；路径切换后焦点进入主内容，更新筛选参数时不抢走输入焦点。“跳到主要内容”直接移动焦点，避免改变 hash 路由。
- 首次打开页面保留正常的键盘顺序；后续路径切换和跳转主内容的焦点提示集中在页面标题，避免给整页内容加边框。

本轮 Vue TypeScript 检查和生产构建通过。人工浏览了真实教学班数据在 320px、375px、768px、1920px 下的界面，以及课程门类的深色筛选面板；操作了加入/移除候选、管理与返回、移动筛选关闭及菜单 Escape。原生抽屉关闭后页面滚动恢复，焦点回到筛选按钮；管理与返回操作聚焦相应标题。没有增加自动化测试文件。

## 第三轮：教室单日时间轴

按用户选择，参考原站教室查询的排列方式，将本站的教室大卡片改为单日占用时间轴。

- 当前页 12 间教室共用纵向时间刻度，图内横向滚动，刻度固定在左侧。绘图区高 360px、教室列最小宽度 84px，只展示公开记录实际涉及的地点。
- 按实际起止时间定位记录，裁切查询时段以外的部分；重叠记录并排展示，短记录保留真实比例。密集并列记录的全文通过教室详情和悬停提示读取。
- 教室编号打开全天全部类型的记录，标记与查询时段重叠的项目；图中类型筛选不改变综合全部类型的时段状态。时刻缺失或无效的记录保留计数与未知标注。
- 桌面筛选横向排列，手机日期和时段始终可见，其余条件复用原生筛选抽屉；状态、容量和校区放入更多条件，日期和时段在清除筛选后保留。
- 使用边界与未定位记录合并为可展开说明，关键提醒及缺少地点的记录数始终可见。图例集中展示，移除各教室卡片内重复的说明。

人工检查了 320px、375px、768px、1440px 和 1920px，以及深浅主题、手机筛选关闭与焦点返回、时间轴横向滚动、全天详情、未知状态、无记录和无效日期/时段。2026-10-10 的真实记录涉及 217 间教室；第一间教室详情有 5 条记录，其中 4 条与 08:00–18:00 重叠，晚间记录仍在详情中保留。临时几何检查覆盖裁切、重叠轨道、相接边界、未知/无效时刻和刻度端点，没有加入永久测试文件。

## 第四轮：替代关系多列布局
