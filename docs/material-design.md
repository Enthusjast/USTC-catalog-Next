# Varlet 与 Material Design 3

迁移日期：2026-10-13。项目名称：USTC-catalog-Next。

## 全站组件

采用 Varlet 3.20.6，主题基于官方 `Themes.md3Light` / `Themes.md3Dark`。
应用栏、菜单、按钮、文本输入、选择框、复选框、信息标签、加载图标和详情容器使用 Varlet。
仅导入使用到的组件样式，路由继续按需加载；预缓存包含应用控件、图标字体和所有路由。

| 位置                      | 职责                                                 |
| ------------------------- | ---------------------------------------------------- |
| `src/app/ui.ts`           | 共用组件注册、中文语言、按需样式、菜单挂载策略       |
| `src/app/theme.ts`        | 深浅主题和蓝色 MD3 颜色角色；控件尺寸与颜色覆盖      |
| `src/components/ui`       | 统一按钮、输入、选择和复选框；兼容已有表单和筛选事件 |
| `src/styles/tokens.css`   | 自定义课表、教室图等界面与 Varlet 颜色角色的映射     |
| `src/styles/material.css` | 自适应导航、圆角、表面层级、分段按钮和页面布局       |

蓝色主色与主色容器配对，背景和浮层采用不同层级的色调表面，操作按钮为圆角胶囊。
深浅主题同时覆盖输入边框、占用详情、课程标签、菜单和焦点轮廓。首屏先恢复已有主题；首次使用按系统深浅偏好选择。页面与 PWA 的背景色同步。

## 桌面与移动端

- 桌面保留横向主要导航和查询侧栏，宽屏结果表使用完整列；手机采用可展开导航、模态筛选抽屉和现有自适应列表。
- 手机输入文字为 16px，避免系统自动放大；常规控件点击区至少 44px。长课程名称换行，表格与专用图表只在自己的区域滚动。
- 选择菜单使用视口定位，保留在原生模态窗口的顶层内，避免落入不可交互的背景；菜单提供 combobox、listbox、option 状态、键盘选择和 Escape。
- 详情保留原生 `dialog` 的背景隔离、焦点约束和关闭后焦点恢复，内容使用 Varlet Paper 和控件；手机面板从顶部保留 16px 间距，底部考虑安全区域。
- 保留日期/时间的浏览器原生输入，应用同一套 MD3 样式；数字输入保留范围校验与 spinbutton 语义。备份文件选择继续使用原生文件输入。
- 教室与课表的定位按钮保留专用几何布局，并使用 Varlet Ripple。教室依然按真实楼栋和楼层展示，112px 列、360px 绘图区、三类配色、独立横向滚动和非悬浮楼栋卡片均保留。
- 尊重 `prefers-reduced-motion`；主题、搜索及查询操作不引入外部字体请求。

## 回归入口

```sh
pnpm test
pnpm run build
pnpm run check:pwa
pnpm run test:browser
```

浏览器回归使用生产构建和隔离样例查询。`material.spec.ts` 覆盖五种宽度与深浅主题下的控件操作、菜单边界、导航、主题切换、输入与复选框状态，以及详情内菜单 Escape 和焦点恢复。
原有全站、候选并发、计划浏览、教室、完整导出、离线启动和提示更新回归继续运行。

界面迁移不改变 API、工作区/备份格式与分享参数，不恢复此前删除的说明及查询元数据。
